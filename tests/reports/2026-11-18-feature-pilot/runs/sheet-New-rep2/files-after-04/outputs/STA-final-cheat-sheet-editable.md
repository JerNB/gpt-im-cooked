## Conditional probability and two-way tables

### One worked example

**Question:** What percentage of commuters cycle?

- Reference group: 25 commuters.
- Cases in both groups: 10 commuters cycle.
- Calculation: 10 / 25 = **40.0%**. Use the commuter total, not all 40 students.
- Report: **40.0% of commuters.** The group named by the question is the denominator. Row percentages use the row total; column percentages use the column total.

The reviewed attempt used a row total for a column percentage. Choose the total matching the requested reference group.

**Reporting rule:** Report proportions as percentages rounded to one decimal place, and name the reference group in words.

## Grouped summaries

A grouped summary computes one chosen summary, such as a mean or count, for each non-empty category. If there are four non-empty course sections, the result has four rows, regardless of the number of students. Compare the same kind of summary (mean with mean, count with count); a group mean is not a group total.

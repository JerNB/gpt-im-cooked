## Side 1 — Conditional probability and two-way tables

### Conditional probability (T1)

**P(A | B) = count(A and B) / count(B)**

### Worked example: commuters who cycle

A class has 40 students. 25 commute, and 10 of the commuters cycle. The question asks what percentage of commuters cycle.

1. Reference group: commuters (25).
2. In both the reference group and the event: commuters who cycle (10).
3. Calculate: 10 / 25 = 0.40.
4. Report: **40.0% of commuters**.

The denominator is the reference group, not automatically the whole sample. Course assumptions: equally weighted cases and a non-empty reference group. P(A | B) and P(B | A) usually differ because the reference groups differ.

**Reporting rule:** percentages rounded to one decimal place, with the reference group named in words.

### Two-way table percentages (T2)

- **Row % = cell / row total.** Row percentages add to 100% across each row.
- **Column % = cell / column total.** Column percentages add to 100% down each column.
- Percentages across a row of column percentages need not add to 100%.

## Side 2 — Grouped summaries and scope

### Grouped summaries (T4)

A grouped summary splits cases by a categorical variable and computes one summary (such as a mean or count) per group.

- One output row per **non-empty group**, not per original case.
- Compare groups using the same summary; do not compare a group mean with a group total.

**Example:** mean score for each of 4 non-empty course sections gives **4 rows**, even if there are 120 students.

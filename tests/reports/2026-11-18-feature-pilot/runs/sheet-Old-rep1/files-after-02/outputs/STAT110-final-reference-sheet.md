## Side 1 — Conditional probability and two-way tables

### Conditional probability (T1)

**P(A | B)** means “probability of A among B.” B is the reference group.

**P(A | B) = count(A and B) / count(B)**

- Denominator: number in B, not the whole sample.
- Decide what group the question restricts you to before calculating.
- Order matters: P(A | B) and P(B | A) usually differ because the reference groups differ.
- Course assumptions: equally weighted cases; reference group is non-empty.
- Report as a percentage rounded to **one decimal place**, naming the reference group.

**Example:** 10 of 25 commuters cycle: 10 / 25 = 0.40 = **40.0% of commuters**.

### Two-way table percentages (T2)

For a cell count:

- **Row % = cell / row total.** Row percentages add to 100% across each row.
- **Column % = cell / column total.** Column percentages add to 100% down each column.

**Choose the denominator by the reference group.** If asked for a column percentage, divide by that column’s total. Don’t infer the denominator from where the question’s category appears in the table.

**Check:** name the group first; divide by that group’s total; verify the percentages sum in the expected direction. Percentages across a row of column percentages need not add to 100% (and vice versa).

**Reporting:** every proportion as a percentage to one decimal place, with the reference group in words. Example: “25.0% of remote workers.”

## Side 2 — Grouped summaries and scope notes

### Grouped summaries (T4)

A grouped summary splits cases by a categorical variable and computes a summary (such as a mean or count) for each group.

- Output: **one row per non-empty group**, not per original case.
- Compare groups using the **same summary** (mean with mean; count with count).
- Do not compare a group mean with a group total.

**Example:** mean score for each of 4 non-empty course sections → **4 rows**, even if there are 120 students.

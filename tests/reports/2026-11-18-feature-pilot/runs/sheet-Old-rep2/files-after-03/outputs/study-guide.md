## 1. Conditional probability: choose the reference group first

A conditional probability asks for the share of one group that also belongs to another. For P(A | B), B is the reference group: count the cases in both A and B, then divide by the number in B.

**Course rule:** P(A | B) = count(A and B) / count(B). The reference group must be non-empty and cases equally weighted. Reversing the order usually changes the reference group and the answer. (Notes §1.1–1.4.)

**Example from practice Q1:** 10 of 25 commuters cycle. So 10 / 25 = 0.40 = **40.0% of commuters**. Do not divide by all 40 students: the question asks about commuters.

**Quick check:** Circle the group named after “of” in your sentence answer. Its total is the denominator.

## 2. Two-way tables: row or column is a denominator decision

A two-way table counts two categorical variables at once. For one cell:

- **Row percentage** = cell count / that row's total. Percentages across a row add to 100%.
- **Column percentage** = cell count / that column's total. Percentages down a column add to 100%.

The choice is the same reference-group question as conditional probability. If asked “within [row category], what share [column category]?”, use the row total. If asked “within [column category]…?”, use the column total. (Notes §2.1–2.3.)

**Personalized caution from your 2026-11-17 reviewed attempt:** On a column-percentage item, you selected a row total. Before dividing, name the column category as the reference group and use that column's total. A row of column percentages does not have to add to 100%; each column does.

## 3. Grouped summaries: one result per group

A grouped summary splits cases by a categorical variable and computes one summary (such as a mean or count) for each non-empty group. The output has one row per non-empty group, not one row per original case. Compare like with like: group mean against group mean, or group total against group total. (Notes §3.1–3.3.)

**Historical example:** The 2025 midterm asks for the number of rows when means are computed for 4 course sections. There are **4 rows**, one for each non-empty section. This is historical format evidence, not a prediction about the final.

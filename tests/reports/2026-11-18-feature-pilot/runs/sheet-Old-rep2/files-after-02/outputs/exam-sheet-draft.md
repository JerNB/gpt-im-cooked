## SIDE A — Conditional probability and table percentages

### Conditional probability: denominator = reference group

P(A | B) = count(A and B) / count(B)

Read P(A | B) as “probability of A among B.” B is the group named after “among/of”; use its count as denominator. Require a nonempty reference group and equally weighted cases. Order matters: P(A | B) usually differs from P(B | A). (Lecture notes §1.1–1.4.)

**Example:** 10 of 25 commuters cycle → 10/25 = 0.40 → **40.0% of commuters**. Do not divide by all 40 students.

### Two-way table: choose row or column denominator

| Asked within… | Divide each cell by… | Percentages add to 100%… |
|---|---|---|
| Row category | That row’s total | Across each row |
| Column category | That column’s total | Down each column |

Row/column choice is the reference-group choice. Row percentages in a row sum to 100%; column percentages in a column sum to 100%. Percentages across a row of column percentages need not sum to 100%. (Lecture notes §2.1–2.3.)

**Denominator check:** name the reference group in words before calculating. For a column percentage, use the column total. A prior reviewed answer selected the row total for a column percentage.

## SIDE B — Grouped summaries and scope checks

### Grouped summaries

Split cases by a categorical variable and compute one summary (e.g., mean or count) per **non-empty group**. Output: one row per non-empty group, not one row per case. Compare the same kind of summary (mean with mean; total with total). (Lecture notes §3.1–3.3.)

**Example:** Four course sections → mean per section → **4 rows** (assuming all four sections are non-empty). This resembles a question in the 2025 Midterm 1 paper; it is historical evidence, not a final-exam prediction.

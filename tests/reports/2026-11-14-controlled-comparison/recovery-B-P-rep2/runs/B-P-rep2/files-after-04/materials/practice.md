# CS 101 (synthetic) — Practice set B (P2 loop tracing)

Keys are in practice-key.md. Count only element-to-element comparisons and state what was counted.

**Q1.** A pass compares each adjacent pair in `[4, 1, 7, 3]`. How many element-to-element comparisons?

**Q2.** A pass compares each adjacent pair in `[8, 2, 5, 6, 1, 4]`. How many element-to-element comparisons?

**Q3.** A pass compares each adjacent pair in `[5, 9, 2, 8, 0, 6, 1, 3]`. How many element-to-element comparisons?

**Q4.** A pass compares each adjacent pair in `[0, -1, 3]`. How many element-to-element comparisons?

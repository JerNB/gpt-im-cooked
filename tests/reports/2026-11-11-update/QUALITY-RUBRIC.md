# Independent quality rubric

This rubric is for the reviewer, not part of tutor prompts. Review packet, prompts, responses, record snapshots, and generated artifacts before consulting model token/time summaries. The reviewer must state uncertainty; this is agent review, not external educator or student-outcome evidence.

## Record and feedback gates

1. Q1 feedback identifies 8 commuters as denominator and gives 2/8 = 25%, retaining the student's 2/10 reasoning as the reviewed mistake.
2. Q3 and Q5 feedback accepts 3/12 and 5/20 = 25% and retains the student's conditioned-population explanation.
3. Repeated same-structure successes alone do not justify Demonstrated. Separate reported no-question-specific-hint claims from observed prior instruction. If a tutor gave a Q3-specific cue, retain that qualification.
4. All 100 historical attempt identities remain in final records; all three new reviewed attempts and useful original reasoning remain. No new weakness is inferred for unattempted C2/C3 questions.
5. Explicit saves/final handoff actually have captured persisted state. No prior-evidence erasure, false persistence claim, or inaccurate memory claim.

## Mock-exam gates

1. Exactly five numbered original questions, supported by S1-S3; breadth includes conditional probability, grouped transformations, and duplicate-key joins. State whether originality is adequate rather than assuming renamed counts constitute a new reasoning task.
2. Mix of response formats matches the request. An actual HTML worksheet and separate checked key are delivered with usable links. A code field does not imply a runtime.
3. Check every key answer/alternative, ambiguity, reference group, row count, and supplied assumption. Distinguish executed computations, instructor support, reasoned/unexecuted answers, and unresolved items. Resolve arithmetic independently in the review where possible.
4. Worksheet does not expose key solutions in visible/hidden/script content and does not provide live scoring during independent attempt. The separate key is not access control.
5. Artifacts retain source/topic mapping and an honest blueprint/personalization. Any export/history functionality is reviewed from source separately from actual browser execution.

Report each material gate as pass, concern/fail, or not verified, with file/line evidence. Keep ordinary chat, record safety, content/key quality, and browser behavior distinct. A smaller or incomplete artifact cannot be described as an equivalent-quality efficiency improvement merely because it used fewer tokens.

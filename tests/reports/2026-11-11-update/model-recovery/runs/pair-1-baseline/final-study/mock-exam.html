Question 4: Two pipelines — pseudocode trace

A six-row table contains four observations from site N and two from site S. Trace the following pseudocode. State the row count of A and B, and explain why they differ.

A = GROUP_BY(observations, site)
    THEN MUTATE(group_mean = MEAN(value))
B = GROUP_BY(observations, site)
    THEN SCALAR_SUMMARY(group_mean = MEAN(value))

This is descriptive pseudocode, not a package API. No syntax knowledge or code execution is required.

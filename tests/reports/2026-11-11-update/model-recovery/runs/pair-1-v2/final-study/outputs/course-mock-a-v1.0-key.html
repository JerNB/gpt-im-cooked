Question 1: Evaluate a reported rate — Choose one

A shop records 40 orders. Of these, 16 are express orders; 10 express orders arrived on time. An analyst writes: "10/40 is the fraction of express orders that arrived on time." Which evaluation is correct?

Answer: B

VerdictOptionWhy
IncorrectA. The statement is correct because all 40 orders were recorded.False: the recorded full sample is not the conditioned group.
✓ CorrectB. The requested fraction is 10/16; 10/40 instead measures express-and-on-time orders among all orders.True: both the denominator and the interpretation of 10/40 are correct.
IncorrectC. The requested fraction is 16/10 because express orders are the condition.False: reverses the numerator and denominator.
IncorrectD. The requested fraction is 16/40 because there are 16 express orders.False: 16/40 measures express orders among all orders, without counting on-time arrival.

Why: S1 conditions on express orders, giving 10 qualifying orders out of 16 express orders. The full-sample fraction describes a different event.

Answer evidence: Verified computation. Python fractions verified 10/16 = 5/8 = 62.5% and 10/40 = 1/4 = 25%. Each option checked against S1.

VerdictOptionWhy

Question 4: Choose the transformation — Code

Use only these defined pseudocode operations: GROUP_BY(data, region) groups the input by region; MUTATE_MEAN(grouped) attaches the scalar group mean to every original row; SUMMARY_MEAN(grouped) produces one mean row per nonempty group. No other behavior is implied.

The input has 11 observations in four nonempty regions. A report must retain every original observation and add its regional mean. Fill the blank with the required operation, state the output row count, and explain why the other operation fails the report requirement.

grouped = GROUP_BY(data, region)
result = ______(grouped)

Answer:

MUTATE_MEAN; 11 output rows. SUMMARY_MEAN would produce four rows and would not retain every original observation.

Why: The required output has the original row structure with an added group result, which is the mutate-style rule in S2. Accept the completed line result = MUTATE_MEAN(grouped), or equivalent wording that identifies the defined operation and both counts.

Answer evidence: Verified computation. Python used a controlled 11-row, four-group example to verify 11 attached rows and four summary rows. The question uses defined pseudocode; no R or other external-language execution is claimed.

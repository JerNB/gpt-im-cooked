Your answer-format rule

For every proportion: convert to a percentage, round to one decimal place, and name the reference group in words. Write “40.0% of commuters,” not “0.4,” “40%,” or “2/5.” The outline says answers without the reference group lose one point.
Quick routine
1. Identify the group named after “among,” “of,” or “within.”
2. Use that group as the denominator.
3. Count the cases in that group that also meet the target condition.
4. Divide, multiply by 100, round to one decimal, and state the group.

1. Conditional probability — T1

Meaning: P(A | B) asks, “Among cases in group B, what share are also in A?” The vertical bar means “among.” The denominator is the size of B, not the whole sample. The order matters: P(A | B) and P(B | A) generally use different reference groups. These rules assume equally weighted cases and a nonempty reference group. (Notes §1.1–§1.4.)

Example from practice set A Q1: 25 students commute; 10 of those commuters cycle. The reference group is commuters, so 10 ÷ 25 = 0.40 = 40.0% of commuters. The 40 students in the full class are not the denominator.

Common slip

Using the whole sample, or reversing the condition, changes the question. First say the reference group aloud; only then choose the denominator.

Retrieval check

A club has 30 members; 12 are seniors; 4 of the seniors volunteer. What percentage of seniors volunteer? State the group. (Practice set A Q3; check against its key after trying.)

2. Two-way tables — T2

A two-way table counts cases across two categorical variables. Each cell is a subgroup; row and column totals give possible reference groups. A row percentage is cell ÷ its row total. A column percentage is cell ÷ its column total. This is the same denominator decision as conditional probability (notes §2.1–§2.3).

Row percentages add to 100% within each row; column percentages add to 100% within each column. Percentages across a row of column percentages need not add to 100% (notes §2.3).

Personalized correction: Your recorded table attempt chose the row total for a column percentage. Corrective rule: name the reference group, then divide by that group’s total. For a column percentage, stay within that column.

3. Grouped summaries — T4

A grouped summary splits observations by a categorical variable and calculates one summary value (such as a mean or count) for each group. It has one row per non-empty group, not one row per original observation. Compare groups using the same kind of summary; do not compare a group mean with a group total. (Notes §3.1–§3.3.)

Past-paper example: The 2025 Midterm 1 Q3 describes a mean score for each of four course sections. The result has 4 rows, one per section, even though the original data had 120 students. This is a historical example of the rule, not evidence that the final will use the same question.

Check yourself

A grouped report gives the median rent for each of 6 neighborhoods, all non-empty. How many rows should the result have? Explain what each row represents.
